# Fix Date Range Selector Confusion (Issue #4735)

## Summary

Fixed the confusing date range selector by replacing two separate calendars with a single calendar that supports range selection with a double-month layout. Closes #4735.

## Problem

The date range selector showed **two separate calendars side-by-side** (left = start date, right = end date). Users couldn't intuitively select a range — they had to click around both calendars through trial and error to figure out how it worked.

## Solution

Replaced the dual-calendar layout with a **single calendar in range mode** displaying two months side-by-side, allowing users to select start and end dates in one visual view (like booking.com).

## Changes Made

**File: `src/components/metrics/DatePickerForm.tsx`**

- Replaced two `<Calendar>` components with one `<Calendar mode="range" numberOfMonths={2}>`
- Used `selected={{ from: startDate, to: endDate }}` for proper range selection
- `onSelect` callback handles range updates correctly
